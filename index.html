About CSS


What is CSS?
CSS is the language that controls how HTML looks: colors, fonts, spacing and layout.


What does it stand for?
Cascading Style Sheets. "Cascading" means rules flow down and later or more specific rules win.


Why is it important?
It separates content (HTML) from design, so one stylesheet can restyle a whole site.


How it works with HTML
HTML builds the structure. CSS selects elements and applies styles to them.


Advantages
Reusable, faster to maintain, consistent design, responsive on any screen.


Real-world uses
Every website, web app, email template and even many mobile apps use CSS.

Responsive Design


What it means
A responsive page adapts to phones, tablets and desktops.


Media queries
Apply styles only when a condition, like screen width, is true.


Mobile-first
Write styles for small screens first, then add min-width queries for larger ones.


Desktop vs mobile
Desktop: multi-column grids. Mobile: one stacked column with bigger tap targets.
